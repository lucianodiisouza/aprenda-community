Uma página só sua, com foto, uma bio curta e seus links. É o "olá, mundo" de quem
está começando no frontend: dá pra publicar de graça e mostrar pra todo mundo.

## Objetivo

Praticar a estrutura de uma página com **HTML semântico** e estilizar com **CSS**
do zero, sem framework. No fim você entende como um site de verdade é montado.

## Requisitos

- [ ] Uma seção de topo com seu nome, uma foto e uma frase de bio
- [ ] Uma lista de links (GitHub, LinkedIn, etc.) usando `<a>`
- [ ] Usar tags semânticas: `<header>`, `<main>`, `<section>`, `<footer>`
- [ ] Estilizar com CSS: cores, espaçamento e uma fonte legível
- [ ] A página tem que ficar decente no celular (largura pequena)

## Desafios extras

- [ ] Modo claro/escuro trocando só variáveis CSS (`:root` + `prefers-color-scheme`)
- [ ] Publicar no GitHub Pages e compartilhar o link
- [ ] Uma pequena animação de hover nos links

## Dicas

- Comece pelo HTML **sem nenhum CSS**. Se a página já faz sentido só com a
  estrutura, sua semântica está boa.
- Use `max-width` no conteúdo principal pra ele não esticar demais em telas grandes.
- Não precisa de imagem hospedada: `https://github.com/<seu-usuario>.png` já te dá
  seu avatar do GitHub.
