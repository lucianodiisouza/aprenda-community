Duas pessoas digitam "aurora" no mesmo segundo. Uma quer entrar na conta. A
outra quer comparar com o Trello antes de assinar qualquer coisa. Mesmo
produto, duas páginas completamente diferentes — e você tem só uma chance de
escolher qual das duas você atende.

## O essencial 🟢

**As quatro intenções.**

- **Informacional** — a pessoa quer entender. "O que é sprint de Scrum",
  "como organizar tarefas em equipe".
- **Comercial** — a pessoa quer comparar antes de decidir. "Melhor app de
  gestão de tarefas", "alternativa ao Trello".
- **Navegacional** — a pessoa quer um lugar específico. "Login da Aurora",
  "documentação da API da Aurora".
- **Transacional** — a pessoa quer comprar ou contratar agora. "Assinar plano
  Aurora", "comprar Aurora".

**A intenção mista.** "Qual o melhor app de gestão de tarefas para equipes
remotas" tem a forma de uma pergunta, mas a intenção de uma comparação. É a
forma mais comum das buscas comerciais, e por isso a mais confundida: muita
gente classifica como informacional e escreve um artigo genérico para uma
busca que queria um comparativo.

**A tela muda conforme a intenção.** O Google não mostra dez links iguais
para toda consulta:

- **Informacional** — artigos, vídeos, fóruns, definições.
- **Comercial** — comparativos, site oficial, avaliações, marketplaces.
- **Navegacional** — o site da marca e páginas internas dele.
- **Transacional** — página de produto, tabela de preço, anúncio, loja.

**O formato vem do tipo de pergunta.** A pergunta que a pessoa faz já sugere o
formato que ela espera encontrar:

- "o que", "como", "por que" → artigo que responde direto
- "melhor", "alternativa", "comparativo" → comparativo com critérios explícitos
- "login", "site oficial", "documentação" → página oficial
- "preço", "comprar", "assinar" → página de planos, com botão

**Uma página para cada intenção.** O trabalho de mapear intenção vira uma
tabela simples, e a tabela vira código:

```js
// Cada intenção pede um formato de página diferente.
const FORMATO = {
  informacional: "artigo que responde a pergunta em um paragrafo",
  comercial: "comparativo com criterios explicitos",
  navegacional: "pagina oficial ou central de ajuda",
  transacional: "landing com preco e botao de compra",
};

// As suas paginas e a intencao que cada uma atende.
const paginas = [
  { caminho: "/blog/organizar-tarefas-em-equipe", intencao: "informacional" },
  { caminho: "/comparativo", intencao: "comercial" },
  { caminho: "/ajuda", intencao: "navegacional" },
  { caminho: "/planos", intencao: "transacional" },
];

// Dada a intencao da busca, devolve a pagina que deve responder a ela.
function paginaPara(intencao) {
  const achada = paginas.find((p) => p.intencao === intencao);
  return achada ? achada.caminho : "nenhuma pagina";
}

console.log(paginaPara("comercial") + " -> " + FORMATO.comercial);
```

O código imprime `/comparativo -> comparativo com criterios explicitos`: para a
busca "melhor app de gestão de tarefas", a página que deve vencer é a de
comparação, não um post de blog e não a home.

Daqui sai a consequência prática. Se a Aurora só tem a página `/planos`, ela
atende muito bem a intenção transacional e não tem onde aparecer na busca
comercial "melhor ferramenta de gestão de tarefas para equipes remotas". A
solução não é otimizar a página `/planos` para essa busca: é criar a página que
falta.

**Marca e genérica são buscas diferentes.** "Aurora" é busca de marca: quem
digita isso já sabe que você existe. "Gestão de tarefas para equipes remotas" é
busca genérica: quem digita isso ainda está escolhendo. A genérica traz
volume, a de marca traz conversão. Você precisa das duas — e elas não podem
morar na mesma página.

## Aprofundamento 🟡

**A SERP é a fonte da verdade.** Antes de escolher o formato de uma página,
abra o Google e digite a consulta. Conte o que aparece: se os dez primeiros
resultados são vídeo, a SERP está pedindo vídeo; se são comparativos, está
pedindo comparativo. Nenhum palpite de palavra-chave supera isso, porque a
SERP mostra o que o Google já decidiu que é a melhor resposta para aquela
busca específica.

**Duas páginas, uma busca: canibalização.** Se duas páginas do seu site
disputam a mesma consulta, o motor não sabe qual delas responder — e as duas
perdem força. A correção não é criar uma terceira: é consolidar em uma página
melhor e redirecionar a outra.

**A intenção muda com o tempo.** "Trello" era uma busca comercial e virou
navegacional conforme a base de usuários cresceu. Daqui a dois anos, "Aurora"
pode ter mudado de lugar. Reavaliar a intenção das suas páginas de marca faz
parte da manutenção, não é uma tarefa de lançamento.

> Dica: se você vai escrever uma página para uma busca, digite a consulta no
> Google antes e olhe quem já está no topo. Esse é o formato que o motor já
> validou para aquela busca.

## Pra quem quer ir além 🔴

**Quando uma página atende a duas intenções.** A página `/planos` da Aurora
serve a intenção transacional ("assinar plano") e, para quem já conhece a
marca, também à navegacional ("aurora planos"). Isso não é defeito: a
intenção dominante define o formato da página, e o resto vira navegação
interna. O defeito é quando duas páginas do mesmo site disputam a mesma
busca.

**Mapear a intenção de um site grande.** Comece pelo que já existe: as páginas
com mais impressões revelam a intenção real, porque foi o mundo que te disse o
que procurava. Depois confira se o formato de cada página bate com a intenção
declarada — e essa checagem é a base do módulo de medição, mais adiante na
trilha.
