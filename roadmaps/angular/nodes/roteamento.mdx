O router transforma uma SPA em várias telas navegáveis. Em vez de controlar a
tela atual com `if` no componente principal, você declara rotas e deixa o Angular
renderizar o componente certo.

```ts
export const routes = [
  { path: "", component: DashboardComponent },
  { path: "trilhas/:id", component: DetalheTrilhaComponent },
];
```

Rotas também carregam parâmetros, protegem áreas e ajudam a dividir código por
feature conforme o app cresce.

- **Path** define a URL.
- **Component** define a tela renderizada naquela URL.
- **Route params** carregam ids como `:id`.
- **Lazy loading** evita baixar o app inteiro de uma vez.
