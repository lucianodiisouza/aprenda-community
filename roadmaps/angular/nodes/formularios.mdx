Formulário é onde o usuário entrega dados para o app. Angular tem formulários
template-driven e reactive forms; para apps médios e grandes, reactive forms
costumam deixar validação e estado mais explícitos.

```ts
form = new FormGroup({
  titulo: new FormControl("", { nonNullable: true }),
});
```

Com reactive forms, o estado do formulário fica em objetos TypeScript. O template
renderiza campos e mensagens, mas a regra principal fica testável.

- **FormControl** representa um campo.
- **FormGroup** agrupa campos relacionados.
- **Validators** impedem dados inválidos antes do submit.
- **Forms tipados** reduzem erro ao ler valores.
