Testes em Angular servem para provar comportamento: service calcula certo,
componente reage ao input, formulário valida e fluxo importante não quebra.

```ts
it("deve somar tópicos concluídos", () => {
  expect(totalConcluido([{ feita: true }, { feita: false }])).toBe(1);
});
```

Comece testando lógica pura e services. Depois teste componentes onde existe
risco real de regressão: formulários, fluxos com rotas e telas com estado.

- **Teste unitário** cobre função, pipe, service ou componente isolado.
- **TestBed** monta componentes com dependências do Angular.
- **Mocks** substituem APIs e services externos.
- **DevTools** ajuda a entender árvore de componentes e performance.
