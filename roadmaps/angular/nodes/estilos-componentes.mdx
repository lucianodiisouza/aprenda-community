Cada componente pode ter seu próprio CSS. Isso ajuda a manter o estilo perto da
interface que ele afeta e reduz conflito entre telas.

```ts
@Component({
  selector: "app-progresso",
  template: `<div class="barra"><span></span></div>`,
  styles: [`
    .barra { height: 8px; background: #e5e7eb; }
    .barra span { display: block; width: 60%; height: 100%; }
  `],
})
export class ProgressoComponent {}
```

O ponto não é colocar todo CSS inline. O ponto é entender o escopo do estilo e
escolher entre `styles`, `styleUrl` e estilos globais.

- **Estilo local** pertence ao componente.
- **Estilo global** serve para tokens, reset, layout base e temas.
- **Classes pequenas** deixam o template previsível.
- **Consistência visual** vale mais que inventar padrão novo a cada tela.
