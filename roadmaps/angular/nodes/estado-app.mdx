Estado é tudo que muda e afeta a tela: usuário logado, filtros, carrinho,
progresso, cache de API e preferências. O erro comum é usar uma ferramenta grande
antes de entender o tamanho real do problema.

```ts
@Injectable({ providedIn: "root" })
export class ProgressoStore {
  concluidas = signal<string[]>([]);
}
```

Comece simples: estado local no componente, depois service com signals ou RxJS.
Bibliotecas como NgRx fazem sentido quando o fluxo tem muita tela, evento e regra
compartilhada.

- **Estado local** pertence a uma tela pequena.
- **Service store** compartilha estado entre componentes próximos.
- **NgRx** ajuda quando o app precisa de fluxo previsível e depuração forte.
- **Cache** não é a mesma coisa que estado de interface.
