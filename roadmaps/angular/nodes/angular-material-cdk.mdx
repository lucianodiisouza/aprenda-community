Angular Material entrega componentes visuais prontos. O CDK entrega peças de
comportamento sem impor a aparência: overlay, drag and drop, acessibilidade,
tabelas e padrões de interação.

```bash
ng add @angular/material
```

Use Material quando o objetivo é montar UI consistente rápido. Use CDK quando
você precisa do comportamento, mas quer desenhar o visual com seu próprio design
system.

- **Material** acelera formulários, menus, diálogos, tabs e tabelas.
- **CDK** resolve interações complexas sem prender ao tema visual.
- **Acessibilidade** melhora quando você usa componentes bem testados.
- **Tema** deve ser configurado cedo para evitar retrabalho visual.
