Services guardam lógica que não pertence diretamente à tela: buscar dados,
compartilhar estado, encapsular regras e conversar com APIs. A injeção de
dependências entrega esses services para quem precisa deles.

```ts
import { Injectable } from "@angular/core";

@Injectable({ providedIn: "root" })
export class TrilhasService {
  listar() {
    return [{ id: "angular", titulo: "Angular" }];
  }
}
```

Um componente chama o service, mas não precisa saber como ele foi criado. Isso
reduz acoplamento e facilita testes.

- **Service** concentra regra reutilizável.
- **`providedIn: "root"`** cria uma instância compartilhada no app.
- **DI** evita instanciar dependências manualmente.
- **Componentes finos** ficam mais fáceis de manter.
