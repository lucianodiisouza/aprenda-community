Agora construa um dashboard em Angular para acompanhar estudos. Ele precisa ter
telas, formulário, dados compartilhados, integração HTTP simulada ou real, estado
e build de produção.

## Requisitos

- [ ] Dashboard com cards de resumo
- [ ] Tela de detalhes de uma trilha usando rota com parâmetro
- [ ] Formulário para criar uma trilha ou meta
- [ ] Service centralizando leitura e escrita dos dados
- [ ] Estado de carregando, erro e vazio
- [ ] Lista filtrável por status
- [ ] Build final com `ng build`

## Desafios extras

- [ ] Persistir no `localStorage`
- [ ] Criar uma versão com API fake usando JSON Server ou mock service
- [ ] Usar Signals para estado local e RxJS para chamadas assíncronas
- [ ] Adicionar Angular Material em formulário, cards e tabela
- [ ] Escrever testes para service e formulário

> Dica: não comece pelo visual perfeito. Primeiro faça o fluxo funcionar de ponta
> a ponta: listar, criar, marcar como concluído e navegar.

Depois desse projeto, você já tem base para entrar em temas de produção:
autenticação, guards, interceptors, bibliotecas internas, SSR mais avançado e
arquitetura de apps grandes.
