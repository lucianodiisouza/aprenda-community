Componentes são os blocos da tela. No Angular moderno, componentes standalone
podem importar diretamente o que usam, sem depender de um `NgModule` para cada
feature.

```ts
import { Component } from "@angular/core";

@Component({
  selector: "app-card",
  standalone: true,
  template: `<article>{{ titulo }}</article>`,
})
export class CardComponent {
  titulo = "Minha trilha";
}
```

Um bom componente tem uma responsabilidade clara: exibir uma lista, representar
um card, receber dados ou emitir uma ação.

- **Selector** é o nome usado no HTML para renderizar o componente.
- **Template** mostra a estrutura visual.
- **Classe** guarda dados, métodos e dependências.
- **Imports** declaram outros componentes, pipes e diretivas usados ali.
