# Decisões editoriais - Angular

## v1.0.0 - 2026-08-26

- A trilha serve para levar quem já conhece a base da web para aplicações
  Angular maiores, com organização de código, rotas, formulários, APIs, estado,
  testes e publicação.
- O roadmap.sh Angular foi usado como referência de cobertura geral, sem copiar
  descrições; os tópicos foram adaptados para o formato do Aprenda, com
  explicação curta em PT-BR e links externos oficiais.
- A ordem é linear e cobre 24 nós para facilitar consumo por
  iniciantes/intermediários vindos da trilha Frontend e da trilha TypeScript.
- O foco é Angular moderno com componentes standalone, Signals e `@defer`, sem
  abrir uma trilha paralela sobre AngularJS ou padrões legados.
- Angular Material/CDK entra como nó opcional porque é comum em apps reais, mas
  não é pré-requisito para entender o framework.
