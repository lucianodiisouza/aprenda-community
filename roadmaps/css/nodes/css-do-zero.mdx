Bem-vindo à trilha de CSS. Se você nunca escreveu uma linha de
estilo na vida, **este é o lugar para começar**. Se você já programa
em outras linguagens e quer entender como a web ganha cor, layout e
movimento, também.

Este primeiro nível cobre o **fundamental**:

- O que é CSS e como ele se conecta ao HTML
- Como incluir CSS numa página (inline, interno, externo)
- Os seletores básicos (tag, classe, ID, atributo)
- Cores (nome, hex, RGB, HSL)
- Tipografia (fontes, tamanhos, peso, altura de linha)
- Box model (margin, border, padding, content)
- Display (block, inline, inline-block, none)
- Unidades (px, em, rem, %, vh, vw)
- Pseudo-classes básicas (:hover, :focus, :active)
- DevTools do navegador

São **10 nós**. O ritmo é de um por dia se você fizer 30 minutos por
sessão - 2 semanas pra fechar o nível. Pode ser mais rápido se você
já tem familiaridade com HTML, mais lento se for muito iniciante.
Tudo bem. O importante é **não pular o box model** e **não pular o
DevTools** - eles vão te salvar daqui pra frente.

> Se você já entende o básico e quer ir direto para layout, pode
> pular para o nível **CSS Intermediário** (próximo tópico). Mas
> volte pro básico se algo no intermediário parecer "mágico demais"
> - o fundamento é o que destrava o resto.

Quando você terminar este nível, vai ter todo o vocabulário para
lidar com **qualquer tutorial de CSS** que encontrar na internet.
Daí pra frente é refinar, aprofundar, dominar.
