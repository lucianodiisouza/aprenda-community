**Tailwind CSS** é um framework de **utility-first**: em vez de escrever
classes com nome semântico (`.botao-azul-grande`), você aplica pequenas
classes de propósito único direto no JSX.

```jsx
<button className="rounded-md bg-brand-green px-4 py-2 font-bold text-black hover:bg-brand-green/80">
  Salvar
</button>
```
