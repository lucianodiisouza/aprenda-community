Você chegou ao fim da trilha de Frontend. Hora de **construir**, não só
ler. Escolha um dos projetos abaixo — qualquer um puxa React, rotas, forms,
fetch, acessibilidade e deploy. Tudo que essa trilha cobriu.

## Sugestões

- **Lista de tarefas (to-do)** — adicionar, marcar como feita, remover,
  persistir no `localStorage`. Prática de state, formulários e effects.
- **Buscador de filmes** — consome a [OMDb API](https://www.omdbapi.com/)
  (gratuita com chave) e mostra pôster, nota e sinopse. Prática de fetch,
  loading states e tratamento de erro.
- **App de previsão do tempo** — consome a [Open-Meteo](https://open-meteo.com/)
  (gratuita, sem chave) para mostrar a temperatura de uma cidade digitada.
- **Dashboard de GitHub** — digita um usuário e mostra repositórios
  públicos, estrelas e linguagens. Prática de fetch, componentes
  reutilizáveis e talvez um gráfico simples (Recharts).

## Critério de "pronto"

1. Funciona sem travar.
2. **Acessível** — testou com `Tab` e (idealmente) leitor de tela.
3. Responsivo — funciona em mobile e desktop.
4. README com: o que é, como rodar, decisões de arquitetura, o que você
   aprendeu.
5. **No ar** — deploy no Vercel, Netlify ou GitHub Pages (todos têm
   tier gratuito). Cole a URL no LinkedIn.

## Compartilhe

Poste no LinkedIn, mande para amigos, comente em uma issue no nosso
GitHub com a tag `meu-projeto`. Mostrar o que você fez — mesmo
"imperfeito" — é o que mais evolui.
