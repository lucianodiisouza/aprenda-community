**HTML** (HyperText Markup Language) é a **estrutura** de uma página. É um
arquivo de texto cheio de **tags** que dizem o que é cada parte: "isso é um
título", "isso é um parágrafo", "isso é uma imagem", "isso é um link".

```html
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <title>Minha primeira página</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Esse é meu primeiro parágrafo.</p>
    <a href="https://exemplo.com">Um link para outro lugar</a>
  </body>
</html>
```
