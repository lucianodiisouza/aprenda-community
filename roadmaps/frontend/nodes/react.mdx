**React** é a biblioteca mais usada para construir interfaces web
modernas. A ideia central é simples: você divide a tela em **componentes**
reutilizáveis — cada um é uma função que devolve **HTML** (mais ou menos).

```jsx
function Botao({ texto, onClick }) {
  return <button onClick={onClick}>{texto}</button>;
}

function App() {
  return (
    <main>
      <h1>Meu app</h1>
      <Botao texto="Salvar" onClick={() => alert("salvo!")} />
    </main>
  );
}
```
