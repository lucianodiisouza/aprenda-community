Antes de escrever a primeira tag, vale entender **como a web funciona por
baixo dos panos**. Não precisa decorar — só ter o mapa mental certo.

A ideia básica:

1. Você digita `aprenda.oprimo.dev` no navegador.
2. O navegador (**cliente**) pergunta a um computador no mundo (**servidor**)
   "me dá o conteúdo desse endereço".
3. O servidor responde com um arquivo de texto (HTML, na maioria das vezes).
4. O navegador lê esse texto, baixa mais coisas que ele referencia (CSS, JS,
   imagens) e **monta a página** na tela.

Esse "pedido e resposta" segue um protocolo chamado **HTTP** (HyperText Transfer
Protocol). Tudo na web — desde ver uma foto até enviar um formulário — é uma
variação disso.

Para começar a construir para a web você precisa entender três peças:

- **HTML** — a estrutura (títulos, parágrafos, imagens, links).
- **CSS** — a aparência (cores, fontes, espaçamento, layout).
- **JavaScript** — o comportamento (cliques, animações, carregar dados).

Essa trilha segue exatamente essa ordem.
